The evidence pointers below identify repository-relative paths and named rows,
sections, JSON cases, or test functions. Regression tests show implementation
contracts, not independent human intent. The pre-v3 historical report is diagnostic
evidence only; its old statuses/winners must never overwrite current expectations.

For all cases, independent reviewers must explicitly accept the shared registered-
order preview scope, independent 2026-04-01 snapshot, current configuration and
tie rules, preview-only side effects, and tool-backed estimates. If they reject
these shared assumptions, reopen affected cases. READY means no additional blocker
under this scope, not that these shared conventions have human ratification.

No exact recommendation winner is required. Configured-score, fastest, lowest-risk,
and cheapest-on-time predicates use eligible permitted candidates and the documented
tie order. A refusal target is an identity assertion, not a recommendation winner.
Review/refusal alternatives may be late, which must be disclosed. R21's cheapest
predicate first filters by the continuous deadline criterion. Historical W5 is
not an independent exact-winner label. R09's fastest and R27's lowest-defects
predicates remain separate from default configured policy.

Temporal phrases are role-specific: R02 last October and R19 last week identify
history/reference context; R12 this week scopes the current exclusion; R27 last
month explains preference; R28 this week cannot supersede explicit Mar 29. R15
asap and R29 go out this week need expectation refinement; R01/R16 today concerns
dispatch. No unsupported calendar deadline should be fabricated from these phrases.

Omitted quantity/deadline on a uniquely resolved order is retrieved, not extracted
or queried redundantly (R08/R11/R14/R24). Explicit uncertainty remains blocking
(R01/R05). For R03/R15/R19/R29, absence of secondary needs and correctly deferred
secondary needs should be considered for equivalent acceptance, but the current
null deferred expectation does not encode that allowed-state relation. Recommendations
below propose it; no requirement has silently been added or removed.
