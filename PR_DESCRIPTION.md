# Pull request description

## Summary

- Add a deterministic generator for supplementary chat training and test cases, with matching rubrics.
- Add support for selecting the supplementary splits in the chat evaluation runner.
- Document the evaluation sets, results, and limitations.

## Evaluation

- Training: 70 cases completed; 67 passed the generated behavior rubric.
- Testing: 30 cases completed; 29 passed the generated behavior rubric.
- Extraction checks passed for all 100 cases.
- Tool-integrity checks passed for all 100 cases.

The failed training cases were TR123, TR126, and TR129. The failed test case was TE095.
The raw run artifacts are local and are not included in this pull request.

## Limitations

The cases and rubrics are generated by construction, not human-adjudicated gold labels.
The behavior pass rates are not overall model accuracy. The runs assess one initial
response per request and do not establish multi-turn clarification quality or full
explanation faithfulness.
